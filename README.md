## 👋 About Us

**yea-kasane-teto**는  
AI를 더 쉽고 직관적으로 이해할 수 있도록,  
학습과 실습을 연결하는 교육형 웹 서비스를 만드는 팀입니다.

우리는 단순히 개념을 읽는 데서 끝나는 것이 아니라,  
직접 조작하고 시각적으로 탐구할 수 있는 학습 경험을 만드는 것을 목표로 합니다.

현재는 AI 입문자를 위한 인터랙티브 학습 플랫폼  
**AIN (AI에 들어가다)** 를 중심으로 프로젝트를 진행하고 있습니다.

## 🚀 Ongoing Projects

### AIN — AI에 들어가다

> 복잡한 AI 이론을 직접 보고, 만지고, 이해하는 인터랙티브 학습 플랫폼

AIN은 인공지능을 처음 공부하는 학습자가  
기초 개념부터 머신러닝, 딥러닝까지  
단계적으로 학습할 수 있도록 돕는 웹 서비스입니다.

단순한 텍스트 설명을 넘어서,  
수식의 값과 알고리즘의 동작을 직접 조작하며  
시각적으로 이해할 수 있는 학습 경험을 제공하는 것을 목표로 합니다.

#### Project Repositories

| Repository | 설명 |
|-----------|------|
| [AIN-main](https://github.com/yea-kasane-teto/AIN-main) | AI 학습 로드맵 메인 페이지 및 통합 인터페이스 |
| [AIN-sehyeon](https://github.com/yea-kasane-teto/AIN-sehyeon) | AI 기초 개념, AI/ML/DL 소개, 인터랙티브 학습 콘텐츠 |
| [AIN-sanghyo](https://github.com/yea-kasane-teto/AIN-sanghyo) | 필수 수학, 경사하강법, 머신러닝 실습 콘텐츠 |

## 🎯 Our Goal

- AI 입문자를 위한 체계적인 학습 로드맵 제공

- 머신러닝/딥러닝 학습 콘텐츠 확장
